# NZ Chrome

Браузерное расширение (Chromium Manifest V3) для точечного доступа к **Gemini**, **Claude**, **ChatGPT**, **AI Studio**, **NotebookLM** и **Google Labs** через ваш или локальный прокси (например, NetZapret, Xray, Clash).

Весь остальной трафик браузера (включая вход в Google-аккаунт `accounts.google.com`, видео, банки и обычные сайты) идёт напрямую.

## Возможности

- **Точечный PAC-скрипт (`chrome.proxy`):** проксируются только домены выбранных сервисов ИИ. При падении прокси запросы не откатываются молча на прямой IP.
- **Таблица маршрутов с доказательством работы:** маршрут, на котором реально открылся интерфейс Gemini, Claude или ChatGPT без регионального отказа, стоит выше просто быстрого маршрута.
- **Контроль страны выхода:** каждый маршрут проверяется через `cp.cloudflare.com/cdn-cgi/trace`; прокси с выходом в заблокированных регионах (`RU`, `BY`, `CN` и т. д.) автоматически отключаются.
- **Автопереключение при геоблоке и подсказка на `/sorry`:** детектор на странице распознаёт региональный отказ (нарастающая пауза 2 мин → 10 мин → 1 ч → 6 ч) и несовпадение IP на проверке `google.com/sorry` (с точным проксированием `=google.com` и `=www.google.com` без захвата остальных поддоменов Google).
- **Свои и локальные прокси:** `http://`, `https://`, `socks5://`, `socks4://` и быстрые пресеты локальных прокси. Пароли скрываются в интерфейсе и журнале.

> Ограничение Chromium: браузер не передаёт логин и пароль для SOCKS5-прокси в PAC-скрипте. Для прокси с авторизацией используйте `http://` или `https://`, либо локальный прокси без пароля.

## Установка (Chrome / Edge / Яндекс.Браузер / Brave)

1. Скачайте и распакуйте архив из [Releases](https://github.com/RixyPow/nz-chrome/releases) (или клонируйте репозиторий).
2. Откройте `chrome://extensions` (или `edge://extensions`, `browser://extensions`).
3. Включите **Режим разработчика** (Developer mode).
4. Нажмите **Загрузить распакованное расширение** (Load unpacked) и выберите папку с файлом `manifest.json`.
5. Закрепите иконку **NZ Chrome** на панели браузера.

## Как включить локальный прокси в NetZapret

Если вы пользуетесь [NetZapret](https://github.com/RixyPow/netzapret), можно направлять через него только нужные сервисы ИИ в браузере (в том числе без включения системного TUN):

1. Откройте **NetZapret** и перейдите на вкладку **VPN** в левом меню.
2. Убедитесь, что выбран и отвечает зарубежный сервер (например, Польша, Нидерланды, Германия).
3. Прокрутите чуть ниже до карточки **«Локальный прокси»** (`SOCKS5 и HTTP на 127.0.0.1:2080`) и включите её тумблер справа — статус должен стать зелёным (**«Включён»**).
4. Откройте окно **NZ Chrome** в браузере → раскройте **«Локальные пресеты (NetZapret, Xray, Clash)»** → нажмите **«NetZapret / sing-box (SOCKS5 2080)»** (или **HTTP 2080**).
5. Через секунду расширение проверит страну выхода, покажет код страны и задержку, а карточка статуса станет зелёной.

Если на публичном VPN-сервере при открытии Gemini появляется страница проверки `google.com/sorry` с разными IP (`≠`), включите в **NZ Chrome** тумблер **«Google (капча)»** (или нажмите кнопку на всплывающей плашке прямо на странице) и обновите вкладку.
