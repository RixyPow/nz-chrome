# NZ Chrome

Браузерное расширение (Chromium Manifest V3) для точечного доступа к **Gemini**, **Claude**, **ChatGPT**, **AI Studio**, **NotebookLM** и **Google Labs** через ваш или локальный прокси (например, NetZapret, Xray, Clash).

Весь остальной трафик браузера (включая вход в Google-аккаунт `accounts.google.com`, видео, банки и обычные сайты) идёт напрямую.

## Возможности

- **Точечный PAC-скрипт (`chrome.proxy`):** проксируются только домены выбранных сервисов Google AI. При падении прокси домены Gemini не откатываются молча на прямой IP.
- **Таблица маршрутов с доказательством работы:** маршрут, на котором реально открылся интерфейс Gemini без регионального отказа, стоит выше просто быстрого маршрута.
- **Контроль страны выхода:** каждый маршрут проверяется через `cp.cloudflare.com/cdn-cgi/trace`; прокси с выходом в заблокированных регионах (`RU`, `BY`, `CN` и т. д.) автоматически отключаются.
- **Автопереключение при геоблоке и подсказка на `/sorry`:** детектор на странице распознаёт региональный отказ (нарастающая пауза 2 мин → 10 мин → 1 ч → 6 ч) и несовпадение IP на проверке `google.com/sorry` (с точным проксированием `=google.com` и `=www.google.com` без захвата остальных поддоменов Google).
- **Свои и локальные прокси:** `http://`, `https://`, `socks5://`, `socks4://` и быстрые пресеты локальных прокси. Пароли скрываются в интерфейсе и журнале.

> Ограничение Chromium: браузер не передаёт логин и пароль для SOCKS5-прокси в PAC-скрипте. Для прокси с авторизацией используйте `http://` или `https://`, либо локальный прокси без пароля.

## Установка (Chrome / Edge / Яндекс.Браузер / Brave)

1. Откройте `chrome://extensions` (или `edge://extensions`, `browser://extensions`).
2. Включите **Режим разработчика** (Developer mode).
3. Нажмите **Загрузить распакованное расширение** (Load unpacked) и выберите папку `nz-chrome`.
4. Закрепите иконку **NZ Chrome** на панели и добавьте свой или локальный прокси.
